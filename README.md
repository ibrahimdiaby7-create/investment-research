Independent company analysis and financial modelling portfolio built from public filings. # Wrapped Up
Live app: https://ibra-brief-1.onrender.com/

Wrapped Up is a personal news aggregator I built to consolidate the news, markets and topics I follow into one personalised daily front page.

It pulls content from multiple news sources, allows users to customise their preferred topics and sources, save articles, track selected market data, and generate updated editions based on their preferences.

I built the platform to solve a simple problem: reducing the time spent moving between different news sites while still maintaining a broad view of markets and current affairs.
